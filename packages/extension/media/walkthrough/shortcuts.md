常用快捷键一览。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+D` | 打开/聚焦对话面板 |
| `Ctrl+Alt+N` | 新对话 |
| `Ctrl+Alt+K` | 行内指令编辑选中代码（Cursor Cmd+K 风格） |
| `Ctrl+Alt+E` | 解释选中代码 |
| `Ctrl+Alt+R` | 逐个审查待审变更 |

面板内：`@` 附加文件、`/` 斜杠命令、`Enter` 发送、`Shift+Enter` 换行。

Keyboard shortcuts reference: Ctrl+Alt+D / N / K / E / R.
